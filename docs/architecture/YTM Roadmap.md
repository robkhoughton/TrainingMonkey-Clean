## Protocol

This roadmap follows the vault-wide Idea Capture Protocol (`C:\Users\robho\Documents\VAULT\CLAUDE.md`) — two triggers land into the Landing Strip:

1. **Rob-triggered**: Rob says "capture this" (or similar) about a YTM idea, at any time, in any session — append immediately, no confirmation needed.
2. **LLM-reviewed**: at `/wrap` (session close), Claude scans for candidate new YTM feature/direction ideas (not bugs, not tasks), checks them against the full roadmap file, and asks a yes/no per candidate before adding anything — nothing lands without an explicit answer.

Either route lands a one-line bullet in **Landing Strip**, untriaged.

**Triage** happens periodically (ad hoc, or during `/weekly-review`): sweep the Landing Strip, move each item into its matching category below (or create a new category), and tag it with a status:

- `[idea]` — captured, not yet scoped
- `[planned]` — scoped, not started
- `[in progress]` — actively being built
- `[shipped]` — done and deployed
- `[deferred]` — considered, explicitly not now (note why if non-obvious)

Untagged bullets below the Landing Strip are legacy backlog from before this protocol existed — tag them opportunistically when touched, no need for a retroactive sweep.

  - **Gap 1 (unchanged, still open):** respiration is a standalone narrative aside in the Rx prompt, not part of the structured readiness composite (HRV+RHR+sleep) — the paper's early-warning-score literature (NEWS/MEWS) is built on combining multiple vitals, which consistently outperforms any single one.
  - **Gap 2 (sharpened 2026-09-12):** the 1.15x-baseline trigger is not merely unsourced (absent from `Training_Metrics_Reference_Guide.md`, and not this paper's threshold either — it uses absolute/nocturnal cutoffs) — on nocturnal respiratory rate it is close to *unfireable*. Night-to-night spread in overnight fR is typically well under 1 breath/min, so 1.15x of a ~14 br/min baseline demands a >2 br/min jump, several standard deviations out. Replacement shape: a personal z-score mirroring the HRV/RHR pattern (3-day acute vs 30-day chronic, minimum reading count, variance floor **measured from the athlete's own collected spread, not guessed**), scoped as an illness/substrate *corroborator* rather than a standalone override until there is data to validate a promotion.

Any implementation must degrade silently on absence, and the integrations page copy should name the fields to enable — folds into the intervals.icu discoverability item above.
